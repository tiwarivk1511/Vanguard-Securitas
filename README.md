## 🛡️ Overview

**Vanguard Securitas & Manpower Services** is an enterprise-grade workforce management organization built to safeguard corporate infrastructure, industrial plants, commercial towers, residential complexes, and institutional campuses across India. 

By consolidating **Manned Guarding**, **Mechanized Housekeeping**, and **Enterprise Support Staffing** under a single accountable command structure, Vanguard Securitas eliminates multi-vendor friction, optimizes facility operating expenditure, and enforces uncompromising service benchmarks.

## ⚡ Key Operational Pillars & Features

- **🛡️ Manned Guarding & Security**: PSARA-aligned civilian security guards, industrial sentries, lady guards, gate control, fire wardens, and executive VIP bouncers.
- **✨ Mechanized Housekeeping & Hygiene**: International 4-color microfiber system (Red, Yellow, Blue, Green) preventing cross-contamination with MSDS-certified eco-green chemicals.
- **👥 Enterprise Support Staffing**: Front-desk executives, multi-tasking staff (MTS), corporate pantry stewards, data entry operators, and warehouse helpers.
- **📄 100% Statutory Compliance**: Zero default policy for EPF UAN generation, ESIC IP cards, Minimum Wages direct NEFT bank transfers, and CLRA registers.
- **🌙 24/7 Command Oversight**: Area Field Officers conducting surprise night patrol audits between **01:00 AM – 04:00 AM**.
- **🚀 Structured Mobilization Roadmap**: 4-Phase site onboarding process from Day 1 risk survey to ceremonial Go-Live.
- **🧮 Interactive Cost Estimator**: Real-time manpower budget calculator for security guards & housekeeping attendants.
- **📱 100% Mobile Responsive Light UI**: Modern high-contrast Light Mode (`#F8FAFC`, `#FFFFFF`) with Regal Metallic Gold (`#D4AF37`) and Slate Navy (`#0F172A`) accents.

## 🚀 Getting Started

### Prerequisites
- Node.js `18.x` or higher
- `npm` or `yarn` or `pnpm`

### Installation

1. **Clone or navigate to the project directory**:
   ```bash
   cd "C:/Users/Vikash_Tiwari/Documents/Vanguard Website/vanguard_securitas_web"
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000)

### Production Build & Type Check

To compile and verify an optimized production build:
```bash
npm run build
```
